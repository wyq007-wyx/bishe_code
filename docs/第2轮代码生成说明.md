### 3.2 `config.py` 实现内容

实现了第2轮要求的配置对象与加载逻辑：

- `SimulationConfig`
- `GurobiConfig`
- `ThermalConfig`
- `EnergyConfig`
- `ConfigBundle`
- `load_config(...)` / `load_config_from_mapping(...)`
- `default_config_path()`

实现特点：

1. **分模块配置对象**：仿真、求解器、热模型、能量模型分开建模，后续模块可按需依赖。
2. **缺省值回退**：YAML 中缺失 section 或 key 时自动回退到默认值。
3. **清晰错误信息**：文件不存在、section 类型错误、字段类型错误、数值越界时抛出 `ConfigError`。
4. **单位一致性约束**：内部能量单位固定为 `J`，配置中若不是 `J` 会明确报错。

### 3.3 默认参数落地

`configs/default_sim.yaml` 已固化关键默认参数：

- `simulation.delta_t_seconds = 60`
- `simulation.horizon_slots = 12`
- `gurobi.gurobi_time_limit = 5.0`
- `simulation.energy_unit = J`

并补充了后续模块直接可复用的初值：

- 能量边界与初始电量（`e_max_j` / `e_min_j` / `initial_energy_j`）
- 温度初值与上限（`initial_temperature_celsius` / `t_max_celsius`）
- 环境相关缺省功率（`default_base_power_w` / `default_max_solar_power_w`）

### 3.4 第2轮扩展配置文件

为后续轮次预置：

- `configs/scenarios.yaml`：S1/S2/S3 场景模板
- `configs/gurobi.yaml`：`fast/balanced/quality` 求解参数模板
