## 3. 本轮生成结果

新增主要接口：

- `EnergyStepResult`：单时隙能量核算结果。
- `update_energy(...)`：按功率和时隙长度计算下一时隙电量。
- `update_energy_from_config(...)`：从配置读取 `delta_t_seconds`、`E_min`、`E_max`。
- `is_energy_feasible(...)`：基于未裁剪能量判断一次动作是否越过安全电量下限。

核心公式：

```text
E_load = (P_base + P_com) * delta_t_seconds
E_harv = P_harv * delta_t_seconds
E_raw = E_prev + E_harv - E_load
E_next = clip(E_raw, E_min, E_max)
energy_violation = E_raw < E_min
```

这样既保证 `SystemState.energy_joule` 不低于安全下限，又保留 `energy_unclipped_j` 和 `energy_violation` 用于统计约束违反。

## 4. 测试与验收

新增 `tests/test_energy_model.py`，覆盖：

- `P_com` 增大时 `E_next` 下降。
- `E_next` 不超过 `E_max`。
- 能量不足时裁剪到 `E_min` 并标记 `energy_violation=True`。
