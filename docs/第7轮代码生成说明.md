## 3. 本轮生成结果

新增主要接口：

- `BaseScheduler`：所有调度器的抽象基类。
- `SchedulerResult`：单时隙调度输出，包含 `decisions` 和可选 `solver_trace`。
- `SafeIdleScheduler`：安全空闲策略，每个核心返回 idle。
- `make_idle_decisions(...)`：生成每核心一个 idle 动作。
- `validate_scheduler_result(...)`：校验返回动作中的时间、核心、任务和任务块引用。

`decide(...)` 统一输入：

```text
current_time
tasks
cores
system_state
environment_window
```

统一输出为：

```text
SchedulerResult(decisions, solver_trace=None)
```

## 4. 测试与验收

新增 `tests/test_scheduler_base.py`，覆盖：

- 空闲调度器返回所有核心 idle。
- `validate_scheduler_result(...)` 可检查合法核心 ID。
- 非 idle 决策引用未知任务块时抛出错误。
- `require_all_cores=True` 时可要求调度器覆盖所有核心。
