## 2. 本轮目标

实现 TCN 策略网络模块，先固定模型结构、输入输出 shape 和推理接口。为避免引入额外重量级依赖，本轮采用纯 Python 的确定性 TCN 形状推理器，后续可替换为 PyTorch 实现而不改变调度器接口。

更新文件：

- `tebs_scheduler/src/tebs/learning/__init__.py`
- `tebs_scheduler/src/tebs/__init__.py`

主要接口：

- `TcnPolicyConfig`：配置输入维度、隐藏通道数、动作数、卷积核大小和层数。
- `TcnActionProposal`：记录 TCN 预测动作，包括核心、任务、任务块、分数和 idle 标记。
- `TcnPolicyNetwork.predict_logits(...)`：输入 `H x F` 特征窗口，输出固定长度 logits。
- `TcnPolicyNetwork.propose_actions(...)`：根据 logits 和任务/核心集合生成每核心候选动作。

### 4.4 测试项具体说明

1. `test_tcn_policy_predict_logits_has_stable_shape_and_values`

   使用固定 3 行、3 维特征窗口，配置 `num_actions=6`。测试检查 `predict_logits(...)` 输出长度是否固定，重复调用是否完全一致，并确认经过 `tanh` 后的 logits 落在有效数值范围内。

2. `test_tcn_policy_validates_feature_shape`

   配置期望输入维度为 4，但传入 3 维特征。预期抛出 `TcnPolicyError`，用于保证训练和推理阶段不会静默接受错误特征结构。

3. `test_tcn_policy_proposes_idle_and_task_block_actions_per_core`

   构造一个核心和一个单块任务，检查 `propose_actions(...)` 是否生成 idle 候选和任务块候选。该测试验证策略网络输出能被第20轮约束过滤器消费。
